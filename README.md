# 沪上高二学习作战板

一个面向上海高二学生的轻量学习规划网页，用来把“考试倒计时 + 晚间可用时间 + 科目强弱”转成可执行的当晚学习计划，默认按 `21:00 放学、23:00 睡觉` 的 2 小时夜间窗口设计。

现在它不只排时间，还会按常见上海高二进度模板实时生成：

- 今晚该学的具体模块
- 对应题型和建议题量
- 必须产出的笔记或错题整理
- 可直接跳转的互联网题源入口

## 亮点

- 零依赖纯前端：直接打开静态页面即可运行
- 科目画像：每门课可调整当前分数与目标分数
- 智能排程：根据考试压力、精力值、作业负担动态生成学习块
- 信源驱动内容：每个学习模块运行时实时抓取维基百科信源摘要、配图与原文链接
- 多进度模板：支持高二上/高二下/略快一档与同步/超前/冲刺组合切换
- 本地持久化：使用 `localStorage` 保存你的调节结果
- 可本地预览：附带 `server.ps1` 作为极简静态服务器

## 文件结构

- `index.html`：页面结构
- `styles.css`：视觉样式
- `app.js`：状态管理、优先级计算、学习计划生成
- `server.ps1`：本地静态服务器

## 启动方式

如果你本机支持 PowerShell，可以在项目目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1 -Port 4173
```

然后访问 [http://localhost:4173](http://localhost:4173)。
